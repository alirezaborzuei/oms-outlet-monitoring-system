# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Instead, contact the repository owner privately through GitHub or the contact information listed on the profile.

## Public repository rules

This repository is a portfolio demonstration. Do not commit:

- API keys or access tokens
- Passwords or connection strings
- Production credentials
- Customer or employee data
- Internal company documents
- Proprietary production source code
- Private location or business data

If sensitive information is committed accidentally, rotate/revoke the credential immediately and remove the secret from the repository history using an appropriate history-rewriting procedure.
